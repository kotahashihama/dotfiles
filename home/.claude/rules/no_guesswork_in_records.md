# 記録として残る文書に、推測を混ぜない

計測結果・調査結果・仕様の記述など、**後から参照される文書**には、**実測とそこから計算したものだけ**を書いてください。裏の取れていない見積もりは載せません。
これは全プロジェクト共通の規約です。

**並んだ数字は、全部が同じ顔をしています。** 1 つでも推測が混ざると、読み手はどれが確かなのか判別できず、**文書全体の信用が落ちます**。

## 対象

「その場で読まれて終わる」ものではなく、**後から引かれるもの**。

| 対象 | 対象外 |
| --- | --- |
| 課題管理ツールの調査・計測ページ | 会話の中での見立て |
| ドキュメント・設計資料 | 検討中の下書き |
| PR 説明・補足コメント | 「たぶん〜だと思いますが確認します」 |
| レポート・申し送り | |

## 3 つに分類し、3 つ目は載せない

**書いた数字を 1 つずつ「これはどこから来たか」で分類する。**

| 区分 | 例 | 載せるか |
| --- | --- | --- |
| **実測** | ログの値・API の応答・ファイルサイズ・コードを読んで数えた個数 | **載せる** |
| **実測から計算** | 割合・1 件あたり・単位変換・「N 倍」 | **載せる** |
| **推測** | 「〜前後」「おそらく〜」、**落ちた位置からの逆算**、少ないサンプルからの一般化 | **載せない** |

**答えられないものは消す。** 「たしか測った気がする」は実測ではありません。

## 特に混ざりやすい 3 つ

| 型 | 例 | なぜ気づきにくいか |
| --- | --- | --- |
| **途中で止まったものの逆算** | 「約 90 万行は書けた」（数えていない） | **落ちた位置は分かる**ので、そこから出した数も確かだと感じる |
| **サンプル不足の一般化** | 「N 以上なら成功する」（境界を試していない） | 観測はすべて正しい。**間を試していないこと**だけが抜けている |
| **もっともらしい概算** | 「1 行 100 バイト前後」「パケットは 3 MB 前後」 | 桁が合っているので、検算する動機が湧かない |

**「約」「前後」を付ければ許される、ではありません。** ぼかし語は不確かさを示しますが、**測っていないことは示しません**。読み手は「測ったうえで丸めた」と読みます。

## 書きたいなら、出どころを明示する

推測にも価値はあります。**混ぜずに、区別できる形で置く。**

```
❌ 書けた行数: 約 90 万行
✅ 書けた行数: 未計測
✅ 落ちた段: 検索用テキスト（そこまでは完了している）
```

- **試していない範囲は「試していない」と書く。** 空欄より、未検証と書いてあるほうが強い
- 見積もりを残すなら、**根拠となる式か仮定を併記する**。式が書けないなら、それは推測ですらない

## 検算のしかた

**書き終えたら、数字だけを拾って 1 つずつ問う。** 文章として読み返すと、前後の説明に納得してしまい素通りします。

1. 文書中の数値・件数・割合を機械的に拾う
2. 1 つずつ「実測 / 計算 / 推測」を答える
3. **計算のものは実際に計算し直す**（記憶で「合っていたはず」としない）
4. 推測のものを消すか、未検証と書き換える

**割合や「N 倍」も検算する。** 元の値が実測でも、割り算を間違えれば誤りになります。

## 禁止する挙動

- **推測した数値を、実測と同じ形式で並べること**
- **「約」「前後」を付けて推測を載せること**。ぼかし語は「測っていない」を意味しない
- **途中で止まった処理の到達点を、逆算して件数として書くこと**
- **境界を試していないのに、しきい値として書くこと**（「N 以上なら通る」）
- 数値の出どころを**記憶で判断すること**。計算のものは計算し直す
- 検証できていない項目を**空欄で済ませること**。「未計測」と書けば、後から埋める対象だと分かる

## なぜ

- 記録は**後から判断の根拠に使われる**。推測が混ざると、それを根拠にした判断が連鎖する
- **1 つ見つかると全部が疑われる。** 読み手には区別する手段が無いので、確かな数値まで確かめ直すことになる
- 「約」を付けると書き手は誠実に感じるが、**読み手には測ったうえでの丸めに見える**。伝わっている内容が食い違う
- 未検証と書くのはコストが低い。**空欄や推測で埋めるより、そのほうが次にやることが分かる**

## 例外

- ユーザーが「見積もりでよい」と明示した場合。この場合も**見積もりであることを文書に書く**
- 実測が原理的に取れない対象（本番でしか起きない事象など）。**取れない理由を添える**
