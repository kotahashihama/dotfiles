# 文章は、書き直すたびに全体を確かめ直す

文書を更新したら、**前に確かめた箇所も含めて全部を検算して**ください。一度確かめたことを「確認済み」として扱わない。
**投稿・共有する前に3回**、それぞれ違う観点で見直します。
これは全プロジェクト共通の規約です。

**文書は育ちます。** 書き足すたびに、前の記述との整合・出どころとの一致がずれていく。**確認は書いた時点でしか成立していません。**

## 3回、観点を変えて見直す

**同じ読み方を3回しても、同じ箇所しか見ません。** 周ごとに何を見るかを変える。

| 周 | 見るもの | 通し方 |
| --- | --- | --- |
| **1周目** | **事実** | 数値・識別子・日時を出どころへ戻して照合する。文章としては読まない |
| **2周目** | **筋** | 上から読み、各主張の根拠が本文の中だけで辿れるか。前後で矛盾していないか |
| **3周目** | **形** | 表のセル数・リンク・見出しの階層・表記。**描画結果を見る** |

**3周目を飛ばさない。** 表のセル数が合わない、リンクが切れている、記法が壊れている。**内容を読んでいる限り気づきません**。文字列としては読めてしまうためです。

**対象は文書全般。** 課題管理ツールのページ・PR 説明・レビューコメント・ドキュメント・報告のいずれも同じ。

## 一度確かめた箇所を、点検の対象から外さない

**「前に見たから大丈夫」が最も多い抜け方です。** 確認した記憶が、確認済みという状態にすり替わる。

| 外したくなる理由 | 実際 |
| --- | --- |
| 前の更新で確かめた | **その後の編集で動いているかもしれない** |
| 自分で計算した値だから | 計算の元が変わっているかもしれない |
| 表を丸ごとコピーしただけ | **コピー元が誤っていれば誤りも複製される** |

**毎回ゼロから数え直す。** 差分だけ見るのは、差分が正しく取れているときにしか使えません。

## 出どころが複数あるなら、全部へ戻る

**1つの出どころと照合しただけで「全部一致」と書かない。** 同じ文書の中に、別の系統から来た数値が混ざります。

```
文書中の数値
├─ アプリのログ由来      ← ここだけ照合して「全部一致」と報告した
├─ 監視サービス由来      ← 検算していない。ここに誤りがあった
└─ 自分で計算した値
```

**照合したことを書くなら、何と照合したかも書く。** 「一致を確認した」だけだと、範囲が読み手に伝わらず、自分でも次に絞り込めません。

## 同じ経路で確かめても、同じ誤りが出る

**取り方を間違えていたら、2回取っても同じ値が返ります。** 検算は**経路を変えて**行う。

| 変えるもの | 例 |
| --- | --- |
| **取得方法** | API の別エンドポイント / 別のコマンド / 画面から目視 |
| **統計の種類** | 最初の1点ではなく平均・最大・最小 |
| **集計の窓** | 対象の時間範囲・件数の範囲を変える |
| **単位・粒度** | 合計と1件あたりの両方を出して突き合わせる |

**「もう一度同じコマンドを打つ」は検算になりません。**

## 指摘されてから直すのは遅い

**読み手に見つけてもらう前提で書かない。** 質問がきっかけで誤りが出るなら、**その質問が来なければ誤ったまま**です。

**次の状況では特に確かめ直す。**

| 状況 | なぜ |
| --- | --- |
| **結論を書き換えた** | 前の結論を支えていた数値が、新しい結論では別の意味を持つ |
| **表に行を足した** | 既存の行が新しい行と同じ基準で取れているか |
| **他の人へ渡す直前** | 渡した後の訂正は、相手の作業をやり直させる |
| **「全部確認した」と書こうとしたとき** | **その文を書く根拠が、実際にあるか** |

## 禁止する挙動

- **一度確かめた箇所を、以降の点検で対象外にすること**
- **1つの出どころと照合しただけで「全部一致」と書くこと**
- **同じ取得方法で2回取って、検算したことにすること**
- **照合の範囲を書かずに「確認した」と報告すること**
- 指摘されるまで見直さないこと。**書き直したその場で全体を検算する**
- **1回読み返しただけで投稿すること**。3周し、周ごとに観点を変える
- **形の点検（表・リンク・記法）を省くこと**。内容を読んでいる限り気づかない

## なぜ

- **文書は書き足されるが、検算は書き足されない。** 更新のたびに範囲が狭まり、古い記述が点検されなくなる
- **誤った取り方は再現性がある。** 同じ手順を繰り返しても誤りは消えず、「2回確かめた」という安心だけが残る
- 読み手が誤りを見つけた時点で、**その数値を根拠にした判断が既に進んでいる**ことがある
- **観点を変えないと同じ箇所しか見ない。** 事実を追っているときは筋の飛びに気づかず、筋を追っているときは表の崩れに気づかない。**1周で全部を見るのは無理**

## 例外

- ユーザーが「そのままでよい」と明示した場合
- 一度も編集していない文書を再度読み返す場合（ただし**参照先が動いていないか**は見る）
