# パッケージのスクリプトは run を省いて書く

`package.json` のスクリプトを呼ぶコマンドは、`pnpm run lint` ではなく `pnpm lint` と書いてください。
README・規約ドキュメント・PR 本文・会話への報告、こちらが書くものすべてが対象です。
これは全プロジェクト共通の規約です。

```
❌ pnpm run lint / pnpm run type-check
✅ pnpm lint / pnpm type-check
```

## run を残すもの

**パッケージマネージャ自身のコマンドと同じ名前のスクリプトは、`run` を省くと別のコマンドが動きます。**

| スクリプト名の例 | `run` を省くと動くもの |
| --- | --- |
| `rm` / `remove` | 依存の削除 |
| `install` / `update` / `link` | 依存の操作 |
| `env` / `init` | Node.js の版の管理、`package.json` の作成 |

判定は「 `pnpm <名前>` が、そのパッケージマネージャの組み込みのコマンドに当たるか」。当たるなら `run` を残す。組み込みの一覧は、使っているパッケージマネージャの版のドキュメント（ `pnpm help` ）で確かめる。

## 対象外

- 既存の文書の書き方を、関係ない箇所まで書き換えること。直すのは、自分が書く行と、依頼の範囲で触る行だけ（ `scope_changes_to_the_issue.md` ）
- npm。`npm run <名前>` の `run` は、`test`・`start` などを除いて省けない

## なぜ

- 短く書ける。読む側もコマンドの本体（スクリプト名）だけを見ればよい
- 組み込みのコマンドと名前が重なる場合だけ例外を置けば、省いた形で困ることはない
