# 本番の DB に重いクエリを出さない

本番の DB へ、全件を走査するような重いクエリを出さないでください。流すのがユーザーでも同じです。先に DB を使わない手段（アクセスログ・ストレージの一覧・コード）を探し、DB が要るなら対象を絞って、手元の DB で通してから渡します。どうしても重いクエリが要るなら、重いことを前置きしてから渡します。
これは全プロジェクト共通の規約です。

**本番の DB へ流すクエリを書く・渡す前に、`~/.claude/references/no_heavy_queries_on_production.md` を読む。** DB を使わない手段の選び方、絞り方、前置きに書くこと、禁止する挙動はそちらにある。

## 関連

- `verify_the_check_worked.md` （検査が成立していたかを疑う）: 自分で書いた手順は実物で通してから渡す。本ルールはその手順がクエリで、流す先が本番の場合
- `decide_or_ask.md` （自分で決めるか尋ねるか）: 本番への負荷は取り消せない側。流すかどうかはユーザーが決める
- `background_heavy_work.md` （重い作業の流し方）: あちらは手元で重い処理を流すとき。本ルールは本番へ重い処理を出さないこと
