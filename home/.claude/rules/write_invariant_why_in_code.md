# コードコメントに残す WHY は、不変のものだけにする

コード中のコメントに WHY を書くとき、**その理由が時間とともに自明になるなら書かない**でください。移ろう文脈は PR の `[fyi]` コメントへ置きます。
これは全プロジェクト共通の規約です。

**WHY なら何でも書いてよい、ではありません。** WHY には賞味期限のあるものが混じります。

## 判定は「1 年後も理由として成立するか」

| 不変の WHY（**コードに書く**） | 移ろう WHY（**PR へ置く**） |
| --- | --- |
| 仕様・ドメインの制約（締め日は 23:59 まで有効） | **その時点のバージョン事情**（「〜から読まれないため」） |
| 避けた落とし穴（ゼロ値が成功扱いになる） | 移行の経緯（旧形式から移した・統合された） |
| 外部システムの決まりごと | 過渡期の回避策（対応版が出るまでの措置） |
| なぜ素直な書き方を採らなかったか | **今は新しいが、いずれ常識になること** |

**「読み手が知らないから書く」ではなく、「読み手が調べても出てこないから書く」で決める。**

ツールやライブラリの仕様は、**公式ドキュメントを引けば出てきます**。一方、**このコードがなぜその形を選んだか**は、書かなければどこにも残りません。

**新しい仕様ほど書きたくなります。** 自分が今調べたばかりで、非自明に感じているからです。**その感覚は数か月で消えます**が、コメントは残ります。

## 移ろう文脈は、捨てずに PR へ置く

**説明が不要なのではありません。** 移行のような変更では、レビュアーはまさにその説明を必要としています。**置き場が違うだけ**です。

| | コードコメント | PR の `[fyi]` コメント |
| --- | --- | --- |
| 読まれる期間 | **永久に残る** | レビュー中だけ |
| 読み手 | 後からコードを読む人 | 今この差分を読む人 |
| 移行の説明 | 数か月で意味を失い、ノイズになる | **ちょうど必要な期間だけ効く** |

**設定ファイルほど溜まりやすい。** 1 行の設定に 3 行の由来が付き、次の移行でまた増える。**設定の意味ではなく移行の履歴**が積み上がります。

### 置き方: 自分の PR へインラインで付ける

**該当する行に、自分でインラインコメントを付ける。** PR 本文へまとめて書くより、**その行を見ている人にその場で届きます**。

```
[fyi]
<説明>
```

1 行目に `[fyi]` を置き、**次の行から本文を書く**（間に空行は入れない）。
レビューの `[must]` / `[imo]` と同じ体系で、**読むだけでよい補足**であることを示します——対応も返信も求めていない、と一目で伝わる。

**自分の PR に自分でコメントを付けるのは、遠慮する場面ではありません。** 書き手にしか見えていない前提を、
レビュアーが差分から読み取るのは無理があります。**先回りして置いておくほうが、質問の往復より安い。**

## 判断に迷ったときの問い

- **その理由を消したら、次に触る人が同じ間違いをするか。** するなら不変の WHY
- **公式ドキュメントを引けば同じことが書いてあるか。** あるなら移ろう WHY
- **「〜から」「〜ため」の主語がバージョンや時期か。** そうなら移ろう WHY

## 禁止する挙動

- **バージョンの過渡期の事情をコードコメントに書くこと**。数か月で自明になり、読み手の時間だけ奪う
- **移行の経緯をコードコメントに書くこと**。差分の意図はコミットメッセージ、レビュー向けの説明は PR が持つ
- **「今は非自明だから」を根拠に書くこと**。非自明さは書き手の側の一時的な状態
- **移ろう文脈だからと、説明ごと省くこと**。PR の `[fyi]` へ置く
- **PR 本文にまとめて書いて済ませること**。該当行を見ている人には届かない。**インラインで付ける**

## なぜ

- コードコメントは**消される機会がほとんどない**。書いた時点の正しさが、そのまま将来のノイズになる
- 移行の説明は**レビュー中に最も価値があり、マージ後に急速に価値を失う**。読まれる期間と価値の曲線が、コードコメントと合っていない
- 一方、**設計判断の理由は時間が経つほど価値が上がる**。当時の検討は誰の記憶にも残らないため

## 例外

- ユーザーが「この理由をコメントに残して」と明示した場合
- **過渡期が終わる時期が読めず、しかもその間に事故が起きうる場合**。この場合も、いつ消せるかを 1 行で添える
