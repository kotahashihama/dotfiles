# ツールを入れるときは、公式の既定値と推奨手順を先に調べる

lint・検査・フォーマッタなどを新しく導入するとき、**閾値や設定値を自分で決める前に、公式の既定値と「段階導入の手引き」を読んで**ください。世の慣行も併せて見ます。
これは全プロジェクト共通の規約です。

**手元の実測から逆算した数字は、根拠を毎回説明することになります。** 既定値には多くの現場を経た蓄積があり、そこから外れるなら**外れる理由**のほうを書くべきです。

## 調べる3つ

| 調べること | どこを見るか |
| --- | --- |
| **既定値** | そのルール / オプションのドキュメント。**「default:」の記載を原文で確かめる** |
| **段階導入の手引き** | 「adopt gradually」「migration」「baseline」等の項。**既存の違反が大量にあるときの正攻法が書かれている** |
| **世の慣行** | 既定が無いオプションでは、公式の例と広く使われている設定のレンジ |

**2つ目が最も見落とされます。** 既定値だけ見て「今は満たせない」と判断すると、**自前の逃げ道を作ることになります**。公式が用意した段階化の仕組みのほうが、たいてい強い保証を持っています。

## 自前の閾値より、公式の段階化を優先する

実際に、未使用コード検出で「現状の総数を閾値にする」形を自分で決めましたが、公式は**種別ごとに `error` / `warn` を切り替える**ことを第一に挙げていました。

| | 自前の総数閾値 | **公式の種別ごと** |
| --- | --- | --- |
| 数字の管理 | **要る**。減るたび手で下げる | 不要 |
| 片付けた種別の保証 | **無い**。他の種別が減れば通ってしまう | **0件が保証される** |

**「総数が増えなければよい」は、種別をまたいだ相殺を許します。** 片付けたはずの種別が再発しても、別の種別が減っていれば検査が通る。

## 既定から外れるなら、理由を書く

外れてよい場面はあります。ただし**そのときは設定ファイルに1行残す**。

| 外れる理由 | 例 |
| --- | --- |
| そのリポジトリの構造上、既定が成立しない | 生成物が多く、既定の対象範囲だと誤検出になる |
| **既定より厳しくしたい** | 既定が warn のルールを error で入れる |
| 移行の途中 | **いつ既定へ戻すかも書く** |

**「今の件数がこうだから」は理由になりません。** それは状態であって判断ではなく、件数が変われば根拠ごと消えます。

## 禁止する挙動

- **既定値を調べずに閾値を決めること**
- **手元の実測値から閾値を逆算すること**。先に既定を見る
- **公式の段階導入の手引きを読まずに、自前の仕組みを作ること**
- **既定から外れた設定に、理由を書かないこと**
- 二次記事の設定例だけを根拠にすること（`verify_before_asserting.md`）
- **設定ファイルのコメントに実測値を書くこと**。数値は設定そのものが持つ（`write_invariant_why_in_code.md`）

## なぜ

- 既定値は**多くの現場を経て決まっている**。独自の数字はその蓄積を捨て、レビューのたびに「なぜその値か」を説明することになる
- 公式が用意した段階化は、**自前の逃げ道より強い保証を持つ**ことが多い。自前だと、思いつかなかった抜け道が残る
- 既定に揃えておくと、**次に触る人がドキュメントを読めば分かる**。独自の値は、決めた人にしか根拠が無い

## 例外

- ユーザーが値を指定した場合
- そのリポジトリの規約が値を固定している場合

## 関連

- `verify_before_asserting.md`（断定の前に裏を取る）: **既定値も裏取りの対象**。記憶や二次記事ではなく原文を読む
- `write_for_installed_versions.md`（入っているバージョンで書く）: あちらは**書くコード**、本ルールは**入れるツールの設定**。どちらも「確かめてから決める」
- `write_invariant_why_in_code.md`（不変の WHY だけ残す）: **設定コメントに実測値を書かない**根拠。数値は設定そのものが持つ
- `treat_user_suggestions_as_proposals.md`（ユーザーの案には賛否を返す）: 値の提案を受けたときも、既定を調べたうえで賛否を返す
- `base_records_on_measurements.md`（記録は実測に基づける）: **実測から閾値を逆算しない**という同じ形。あちらは記録、本ルールは設定が対象
