# 日本語の文章にダッシュを使わない

`——`（全角ダッシュ）や `--` を、**文の途中で言い直し・補足・言いさしを表すために**使わないでください。
これは全プロジェクト共通の規約です。

```
❌ 件数では説明できない——2万件が落ち、10万件が通っている
✅ 件数では説明できない。2万件が落ち、10万件が通っている

❌ 判定は読み手の側——書き手が誠実に感じても意味はない
✅ 判定は読み手の側にある。書き手が誠実に感じても意味はない
```

## 言い換え方

**ダッシュは3つの役目を兼ねています。** どれを担わせていたかで置き換え先が変わります。

| ダッシュの役目 | 置き換え |
| --- | --- |
| **根拠・具体例を足す** | **句点で切って次の文にする**。「〜。〜」 |
| 言い換える | 「つまり」「言い換えると」を使うか、**片方を消す** |
| 補足を挟む | **括弧**に入れるか、**次の文へ出す** |

**多くは句点で切れば済みます。** ダッシュを使いたくなるのは1文に2つのことを詰めているときなので、**分ければ解決する**。

## 対象外

| そのまま | 例 |
| --- | --- |
| **コマンド・オプション** | `--region` `-batch` |
| **範囲の表記** | `364〜378MB`（波ダッシュは別物） |
| **表の区切り** | `\| --- \|` |
| **引用・ログの原文** | 原文を書き換えない |
| **英語の文章** | 英語圏の慣習に従う |

## なぜ

- **書き手には勢いがあるが、読み手には切れ目が見えない。** 日本語は句読点で構造を示すので、ダッシュが挟まると**どこまでが1つの主張か**を組み立て直すことになる
- **1文に2つのことを詰める癖の表れ**でもある。分ければ、どちらの文も短くなって読みやすい
- 全角ダッシュは環境によって**見た目が揺れる**（`—` `―` `–` の判別がつかない）

## 例外

- ユーザーがダッシュを使った文面を指定した場合

## 関連

- `github_one_sentence_per_line.md`（1文ごとに改行し句点を落とす）: **句点で切ればそのまま1行になる**。本ルールで分けた文が、あちらの単位になる
- `no_space_between_number_and_unit.md`（数値と単位の空白）: どちらも日本語の表記を定める
- `concise_first_then_detail.md`（簡潔に）: ダッシュで足した補足は、たいてい削れる
