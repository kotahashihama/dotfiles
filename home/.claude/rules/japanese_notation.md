# 日本語の表記は、数量を詰め、英単語の前後とインラインコードの前後を空ける

会話・PR 説明・コミット・コメント・ドキュメント・コードコメント、こちらが書く日本語すべてが対象です。
これは全プロジェクト共通の規約です。

| 境界 | 空白 | 例 |
| --- | --- | --- |
| 数値 ↔ 単位・助数詞 | 入れない | `2万件` `885MB` `11.2倍` `93.9%` |
| 日本語 ↔ 数字・数量 | 入れない | `全8回` `885MBのメモリ` `1.06msで` |
| 独立した英単語 ↔ 日本語 | 入れる | `Aurora が切る` |
| 英字と日本語が混ざった語 ↔ 日本語 | 入れない | `はJR東日本も` |
| 全角の約物 ↔ 英字・日本語 | 入れない | `「変更履歴」hoge` `（hoge）` |
| インラインコード ↔ 何でも | 入れる。句読点の直前だけ詰める | 親（ `accounts` ）の行数 / 値は `null` になる。 |

判定は「数量か、語か」。`885MB` は1つの量なので前後と詰め、`Aurora` は語なので空けます。

**ダッシュ（ `——` ）で言い直し・補足を挟まない。** 句点で切って次の文にするか、括弧に入れます。

コード・コマンド・引用・ログの原文・英語の文章は対象外です。そのリポジトリの既存の文書が別の流儀で揃っていれば、そのファイルの中では合わせます。

フックが会話・書いたファイル・コードコメント・投稿（ `gh`・MCP・bee ）を検査し、外れていれば差し戻します。差し戻されて判定に迷ったら、`~/.claude/references/japanese_notation.md` を読む。境界ごとの判定・例外・実例はそちらにある。
