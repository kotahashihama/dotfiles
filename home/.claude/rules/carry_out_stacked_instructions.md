# 連続して来た指示は、すべて積んで最後までやりきる

ユーザーが立て続けに指示を出したとき、後から来たものは前のものを打ち消しません。取り消しが明示されない限り、全部を積まれたタスクとして扱い、最後まで片付けてください。
これは全プロジェクト共通の規約です。

## 打ち消しと判断してよいのは、明示されたときだけ

| 形 | 例 |
| --- | --- |
| 取り消し | 「さっきのは無し」「やっぱりいい」 |
| 差し替え | 「そっちじゃなくて、こうして」 |
| 優先の指定 | 「先にこっちだけやって」（残りは積んだまま） |

**新しい指示が来ただけでは打ち消しになりません。** 話題が変わったように見えても、前の指示は生きています。指示が多いときは着手前に積まれた一覧を出す。

## 禁止する挙動

- 後から来た指示だけに応えて、前のものを流すこと
- 積み残しがあるのに「完了しました」と報告すること。途中で終わるなら、何が残っているかを書く
- 優先度を下げて後回しにし、そのまま忘れること。順序は変えてよいが、落とさない

## なぜ

- 落とされたことはユーザーにしか気づけない。こちらは「やった分」しか見えていないので、指摘されるまで完了したつもりでいる

## 例外

- ユーザーが「今はこれだけでいい」と範囲を絞った場合
- 積んだタスクが互いに矛盾する場合。勝手に選ばず、どちらを採るか尋ねる（ `decide_or_ask.md` ）
- 前提が崩れて実行できなくなった場合。黙って落とさず、できない理由を報告する

## 関連

- `decide_or_ask.md` （確認が要らないなら止まらない）: あちらは止まらないこと、本ルールは落とさないこと
- `summarize_after_each_task.md` （各作業後のサマリ）: 1つ終えるごとに報告するが、報告は次へ進まない理由にならない
