# 数値と単位のあいだに空白を入れない

日本語の文章では、数値と単位・助数詞を**くっつけて**書いてください。
これは全プロジェクト共通の規約です。

```
❌ 2 万件 / 21 秒 / 885 MB / 11.2 倍 / 3 ファイル / 1 行
✅ 2万件 / 21秒 / 885MB / 11.2倍 / 3ファイル / 1行
```

## 対象

**数を数えている語すべて。** 助数詞（件・秒・倍・行・本・回・個・人・箇所）も、記号の単位（MB・GB・ms・MiB・vCPU）も同じ扱いです。

| くっつける | 例 |
| --- | --- |
| 助数詞 | `70,000件` `9分45秒` `11.2倍` `3本` |
| 単位記号 | `885MB` `0.688ms` `13.28MiB` `2048MB` |
| 割合 | `93.9%` `-4%` |

**桁区切りのカンマはそのまま。** `70,000件` のように、数値の中の書式は変えません。

## 対象外

| そのまま | 理由 |
| --- | --- |
| **コード・識別子・コマンド** | `memory = 2048` `--limit 10` は元の書式が正 |
| **引用・ログの原文** | 原文を書き換えない |
| **英語の文章** | 英語圏の慣習（`21 s`）に従う |
| **数と単位が係り受けで離れているとき** | 「3つのうち2つ」の「うち」は単位ではない |

## 英語と日本語のあいだには、逆に空白を入れる

**紛らわしいので分けて覚える。** 空白を詰めるのは**数値と単位**のあいだだけで、**英字と日本語**のあいだは空けます。

```
✅ 885MBのメモリ         ← 数量はひとかたまり。前後の日本語とも詰める
✅ 1.06msで安定している
✅ Aurora が接続を切る    ← 純粋な英単語は日本語と空ける
❌ 885MB のメモリ
❌ Auroraが接続を切る
```

| 境界 | 空白 |
| --- | --- |
| 数値 ↔ 単位・助数詞 | **入れない** |
| **日本語 ↔ 数字** | **入れない**（`が20000件` `全8回`） |
| 英字 ↔ 日本語 | **入れる** |
| **数量（数値＋単位）↔ 日本語** | **入れない**（`885MBのメモリ` `1.06msで`） |
| **全角の約物 ↔ 英字** | **入れない**（囲む・区切るのどちらも。下記） |

**空白を入れるのは、独立した英単語と日本語が隣り合うときだけ。** 数量（数値＋単位）は日本語と直接くっつきます。

**判定は「数量か、語か」。** `885MB` は1つの量なので、**前後の日本語ともくっつけます**。`Aurora` は語なので空けます。

**単位だけを見て英字と判定しない。** `ms` は英字ですが `1.06ms` の一部であって、独立した語ではありません。

```
✅ 更新が20000件 / 全8回 / 885MBのメモリ / 1.06msで安定 / Aurora が接続を切る
❌ 更新が 20000件 / 全 8回 / 885MB のメモリ / 1.06ms で安定 / Auroraが接続を切る
```

### 全角の約物との境界には空白を入れない

**囲む約物も区切る約物も同じ扱いです。** 全角の約物はそれ自体に余白を持っているので、足すと空きすぎます。

```
✅ 「変更履歴」hoge  、hoge  。hoge  （hoge）  【hoge】
❌ 「変更履歴」 hoge  、 hoge  。 hoge  （ hoge ）
```

対象は `、` `。` `「` `」` `・` `？` `！` `（` `）` `【` `】` など。

**中身が英字か日本語かで変えない。** `（生成者表示の NOTE は数えない）` のように**混ざるのが実際の書かれ方**で、どこまでを英字と見るかが決まりません。

**半角の約物は対象外。** `(hoge)` は元から余白が狭いので、そのまま書きます。

**半角スラッシュも対象外。** `A / B` は選択肢を並べる記号なので、両側に空白を置く。詰めると `」/ 「` になり、区切りが約物に飲まれて読めなくなります。

## なぜ

- **空白があると1語に見えない。** 「2万件」は読むときに一度分解が入る。数と単位はひとかたまりの情報なので、見た目もひとかたまりにする
- 日本語の組版では**数値と助数詞のあいだに空白を置かない**のが通例。空白を入れるのは英語の慣習で、混ぜると表記が揺れる
- 表のセルでは特に効く。**空白が入ると折り返し位置が増え**、狭い列で不自然に改行される
- **全角の約物を「英字なら空ける」としていた時期があったが、実例が0件だった。** ルール群52本で内側を空けていたのは**この規約自身の OK 例1件だけ**で、他の213件はすべて詰めている。基準が使われていないなら、基準のほうが誤っている

## 例外

- ユーザーが特定の表記を指定した場合
- そのリポジトリの既存文書が空白ありで統一されている場合は、**そのファイルの中では既存に合わせる**（1つの文書で表記が割れるほうが読みにくい）
