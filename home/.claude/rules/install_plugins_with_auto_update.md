# 外部のスキルはプラグインで入れ、自動更新を有効にする

Web から取り込むスキル・フック・MCP サーバーは、取り込み元が配っているプラグインがあればそれで入れてください。プラグインのマーケットプレイスは、すべて自動更新を有効にします。
これは全プロジェクト共通の規約です。

## 道具の形は、更新の経路が整ったものから選ぶ

**同じことができる道具が、いくつかの形で配られていることがある。** 次の順で探し、上に当たるものがあればそれを使います。

| 順 | 形 | 理由 |
| --- | --- | --- |
| 1 | Claude Code の標準の機能 | 入れる手間も更新の手間も無い |
| 2 | 公式のマーケットプレイス（ `claude-plugins-official` ）のプラグイン | 既定で自動更新される。一覧と有効・無効を `/plugin` でまとめて扱える |
| 3 | 提供元の公式の CLI | 人も同じコマンドを打てる。版を固定して入れ、上げるのは手作業 |
| 4 | 提供元の公式の MCP | 設定を手で持つ |
| 5 | 信頼できるサードパーティのプラグイン | マーケットプレイスの自動更新を自分で有効にする（下記） |
| 6 | 自作のスキル・フック・サブエージェント | 保つのは自分 |
| 7 | 非公式の MCP・自作の MCP | 最後の候補 |

**2〜4は、できることで前後する。** 下の形にしかできない操作が要るなら、そちらを選びます。`git` と `gh` のように、CLI で足りて広く使われているものは CLI のままでよい。

**誰が保守しているかも見る。** 公式のマーケットプレイスに載っていても、保守しているのが Anthropic とは限りません。中身が提供元の MCP を呼ぶだけのプラグインもあります。

**プラグインが更新されても、呼び出す外部の本体は更新されない。** 言語サーバーのプラグインは手元の `typescript-language-server` などを呼ぶだけで、本体は Homebrew や mise の側で上げます。

**CLI に寄せたら、MCP のツール名で拾っていた検査を、Bash のコマンドの文字列で拾い直す。** 許可の設定とフックはツール名で当てていることが多く、直さないと素通りします。

2026-10-29 に、手元の道具を次のとおり選びました。

| 道具 | 選んだ形 | 決め手 |
| --- | --- | --- |
| Playwright・context7・言語サーバー | 公式のプラグイン（2） | 自動で更新される |
| Backlog | 提供元の CLI（bee）とスキル（3） | 提供元の MCP（4）より上。添付の中身を取る操作だけは、スクリプトで補った |
| claude-recall・grokbot | 提供元の CLI（3） | MCP は同じ本体の窓口（4） |
| Mermaid | 非公式の MCP（7） | 開いたまま描き直しが反映されるプレビューは、公式の CLI（ `mmdc` ）に無い |
| 1Password | 提供元のプラグインの MCP（5）と CLI の `op`（3） | Environment の変数の一覧と追加は `op` に無いので、MCP も使う |

## 取り込むときは、先にプラグインを探す

取り込み元のリポジトリに `.claude-plugin/marketplace.json` があれば、プラグインとして配られています。

```sh
gh api repos/<owner>/<repo>/contents/.claude-plugin --jq '.[].name'
```

| 見つかったもの | 入れ方 |
| --- | --- |
| プラグイン | `claude plugin marketplace add <owner>/<repo>` → `claude plugin install <plugin>@<marketplace>` |
| スキルのファイルだけ（Gist・リポジトリの `SKILL.md` ） | `~/.claude/skills/` に、取り込み元の形のまま置く |

**取り込み元の形を書き換えない。** 重複の削除・命名の統一・文章の点検による書き直しの対象にしません。更新を取り込むときに差分が出て、取り込み元と見比べられなくなります。

**欲しいスキルが1本でも、プラグインは束で入る。** 何十本もまとめて入るなら、毎回読み込まれる説明と、手元のスキルとの役割の重なりを先に見る。重なりが大きければ、ユーザーへ尋ねる。

プラグインのスキルは `プラグイン名:スキル名` で呼ばれます。手元の写しから乗り換えたら、ルール・スキル・フックの中の呼び名も直す。

## マーケットプレイスは自動更新を有効にする

サードパーティのマーケットプレイスは、既定では自動更新が無効です。`claude plugin marketplace add` は `settings.json` の `extraKnownMarketplaces` に取り込み元だけを書き、`autoUpdate` を付けません。

```json
"extraKnownMarketplaces": {
  "<marketplace>": {
    "source": { "source": "github", "repo": "<owner>/<repo>" },
    "autoUpdate": true
  }
}
```

**足したその場で `"autoUpdate": true` を付ける。** `claude-plugins-official` などの公式のマーケットプレイスは既定で有効なので、書かなくてよい。

## なぜ

- プラグインなら更新が自動で届く。手元に写しを置くと、更新を取り込む仕組みを別に用意することになる（定期実行のジョブなど）
- 自動更新が無効のままだと、入れた時点の版に留まり、取り込み元の修正が届かない。気づくのは不具合を踏んだとき
- 取り込み元の形を保てば、何が変わったかを取り込み元の履歴で追える

## 例外

- ユーザーが特定の版に固定すると決めた場合
