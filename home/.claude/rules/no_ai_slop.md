# 量を出さない。自分の判断を通してから出す

会話・PR 説明・コミット・レビューコメント・ドキュメント、**こちらが書くものすべて**が対象です。
これは全プロジェクト共通の規約です。

[AI slop](https://ja.wikipedia.org/wiki/AI%E3%82%B9%E3%83%AD%E3%83%83%E3%83%97) と呼ばれるものの本質は、労力・品質・意味の欠如と、それを覆い隠す量にあります。「AI が書いたか」は関係ありません。モデルが書いても、手を入れて判断を通したものはスロップになりません。判断が欠けたときになります。

**冗長の排除と、対象を具体的に指すことは `/japanese-tech-writing` が持ちます。** 本ルールは、あちらが扱わない「足す前の判定」だけを持ちます。

## 足す前に、これが無いと読み手は困るかを問う

困らないなら、書かないほうが良い文章になります。

| 足したくなるもの | 判定 |
| --- | --- |
| 節・見出し | その節が無いと読み始められないか |
| 表 | 同じ観点が3件以上あるか。2件なら文で足りる |
| 項目 | 中身が2つなら2つ。3つ目を作らない |
| 補足・前置き | 消して意味が変わるか |

**書き終えてから、節・表・項目の数を見ます。** 消して意味が変わらないなら消す。

## 禁止する挙動

- **量・網羅・体裁を、判断を通した証拠として扱うこと**
- 項目数に合わせず、3つに揃えること

## なぜ

- スロップは体裁が整っている。崩れていれば気づくが、整っていると読み手が中身の薄さに気づくまで時間がかかる
- **量は労力の証明にならない。** むしろ判断を省いたときのほうが増える

## 例外

- ユーザーが特定の文体・分量を指定した場合
- 危険な操作の警告（強調が必要な場面）
